## C. Exact first-return messages, including arbitrary excursions

For any finite simple G and distinguished vertex a, let K_i be the components of G-a and H_i=G[K_i union {a}]. They share only a, and no edges join distinct interiors. A labelled consuming ancestry tree has leaf labels at initial vertices; the two child roots have the same label u and their parent has adjacent label v. All leaves are distinct designated input tokens.

Define a *fragment* at a with side i as such a tree whose root is a, whose other internal vertices are in K_i, and whose leaves are either actual input tokens in K_i or external holes labelled a. It has at least one production, and a never occurs internally below its root: all proper a-nodes are cut into holes. Write (d,h) for its vector of actual interior inputs and number of holes. Let F_i be the set of all these finite fragment types. For q in K_i define P_i,q similarly with root q, no internal a, actual interior inputs and holes. A one-leaf q tree is allowed in P_i,q. A standalone a-hole is NOT a first-return fragment.

Let C_a be the exact nonempty consuming clear-to-a input language. For any set X of nonempty input vectors, write hX for the set of sums of h vectors in X, with0X={0}. Then the following is an equality of least finite-derivation languages, with coordinatewise embedding of d in V(G):

    C_a = least X satisfying
          X = {e_a} union union_i union_(d,h in F_i) (d + hX),
    C_q = union_(d,h in P_i,q) (d + h C_a),      q in K_i.

**Theorem38 (exact first-return composition).** These equations determine every rooted consuming clearing language on G. The rooted stacking language at q is exactly the set of all nonempty finite sums of vectors in C_q. Every first-return or interior-root fragment has EVEN h; the only one-input boundary base is the actual singleton e_a. The equalities apply even when G is bipartite (no clearing threshold is then inferred), and retain every finite returning excursion.

Proof. Take a global clear-to-a tree with more than one leaf. Its last production is from some u in exactly one K_i into a. Starting below the root, cut every first encountered proper node labelled a into a hole, retaining the full cut subtree separately. Every remaining internal graph label is in K_i: moving between components requires encountering a. This gives a finite F_i fragment, and every cut subtree is a nonempty member of C_a. Its exact leaf vector is d plus the sum of those subtree leaf vectors, with no label lost or counted twice. Repeating on cut subtrees terminates, since each is a proper smaller tree. A one-leaf global tree is precisely e_a. Thus every global tree belongs to the least language generated by the displayed equation, not an arbitrary larger fixed point.

Conversely, substitute independently chosen C_a ancestry trees into the labelled holes of a finite fragment derivation, using disjoint designated input labels. All child roots and edges agree, so this is an actual global ancestry tree. Postorder on its exact input labels is a legal schedule; other tokens are untouched. Induction on the finite substitution derivation proves the reverse inclusion. For q in K_i cut all first a-nodes below q instead; the identical argument gives P_i,q(C_a). All output forests at q are nonempty exact sums of clear-to-q trees by the already credited ancestry equivalence, proving the stacking assertion.

For evenness, every external a-hole is a child of a proper internal node, with an a-labelled sibling, because the two child labels in each production are identical. No proper internal a survives the cuts, so that sibling is also a hole. The holes partition into such pairs. Hence h is even. A nontrivial fragment with no actual interior input has h>=4 when it returns to a: h2 gives one output at a neighbor and cannot alone return. The actual e_a base is distinct and never treated as a zero-input hole. QED.

This is a uniform exact message description, not yet a constant-size numerical block message. Infinite fragment sets and least substitution retain excursions that scalar export/net-core rules erase. Diamond/overlapping cycles remain inside one component; separate cycle thresholds cannot falsely treat them as independent. On a cactus, apply the same decomposition at cut vertices while retaining whole cycle fragments. No arbitrary cactus threshold or all-odd-cycle upper follows.

All coordinates are actual token counts. Reducing them to support/residue representatives later requires EXACTLY S008's carries, and nonempty subtree substitutions preserve positive versus zero source. An external hole is a demand for an actual boundary singleton tree with its own cost, not free credit. Fragment forest concatenation is postponed until the common final root is fixed.

**Finite interface consequence.** For a fixed input vector c of mass m, every tree or fragment used in a global derivation has d<=c on actual coordinates and h<=m because each hole substitutes a nonempty tree. It is enough to enumerate fragment input+hole mass<=m, then solve the displayed equations by induction on input mass. A recursive port production has h>=2, so all substituted child inputs are smaller than the full parent; h0 is a constant input fragment. Interior-root languages and nonempty forests obey the same strict smaller-input decomposition. Thus the registered finite evaluator is exact for each named vector, with no guessed conductor or loop truncation.

## B. Extremizers: exact insertion spines and three-component damage

**Lemma39 (one-pebble insertion normal form).** Let c be a nonempty losing configuration for one eligible unrooted goal, and let c+e_w win. Then there is a finite walk w=v_0,v_1,...,v_m=r, m>=1, nonempty input vectors d_0,...,d_(m-1), each clearing exactly to e_(v_i), and, for stacking, an additional possibly empty forest input f stacking at r, such that

    c = sum_i d_i + f,
    c legally reaches sum_i e_(v_i) + K e_r.

Here f is consumed by K unmarked trees rooted at r (K=0 for clearing), and the descendant on the right is losing. Conversely, any such exact partition/trees/walk/forest proves c+e_w wins at r. For a global largest loser the construction exists for EVERY w, including initially empty sites, because massL+1 wins.

Proof. Label the added pebble and choose a consuming winning tree/forest for c+e_w. Follow the unique path from its marked leaf to the root r. At each merge, its sibling is an unmarked nonempty ancestry tree ending at the same current vertex v_i; the next parent is at adjacent v_(i+1). All sibling leaves, together with the unmarked final trees, partition every input of c. Independently replay their disjoint postorder histories to obtain the displayed descendant. A winning descendant would make c winning, so it loses. The marked path cannot have length0: in clearing this would leave c empty; in stacking it would leave an unmarked common-root forest consuming c and making c win. Conversely start with the marked singleton at w and successively merge it with each sibling output along the walk; the final marked root output and all unmarked roots finish the desired goal. QED.

This is a known ancestry mechanism sharpened to an insertion certificate; no priority claim. It replaces an informal 'a spare pebble makes a tree' assertion with all input partitions, arbitrary roots and possible revisits. The walk cannot be assumed simple: exact 3-removal on an edge already uses a returning marked spine. Nor does the existence of spines for all w imply that their siblings can simultaneously be concentrated into one pile.

**Lemma40 (marked deletion frontier).** In any consuming winning forest, remove p designated input leaves. At most p final trees are affected. Evaluate all unaffected final trees and all maximal unmarked subtrees in the affected trees. The remaining input reaches exactly their root-output tokens, plus the unaffected final outputs. An affected tree can expose arbitrarily many sibling subtrees along long marked paths, so there is no bound on the number of frontier tokens in terms of p alone. Reconstructing a win requires a legal consuming tree/forest for this actual frontier, with the prescribed common root if stacking.

Proof. Each removed leaf belongs to exactly one final tree, so the number affected is at most p. Delete all nodes with a removed descendant. Maximal remaining subtrees have pairwise disjoint leaf sets and partition all undeleted input in affected trees. Together with unaffected trees they partition the entire remaining input, so disjoint postorder replay proves the exact descendant assertion. A binary spine of length m can expose m unmarked siblings even with p1, proving that p alone does not bound frontier size; this is a combinatorial ancestry statement, not a claim about the exact minimal forest of each graph. The final reconstruction requirement is precisely the exact ancestry equivalence. QED.

The stronger shortcut 'three removed surplus inputs affect at most two stack components' is REFUTED even when the remaining input is critical. On P3 with center0, the known critical loser c=(0,3,3), mass6 and stack7, has marked extension (0,6,3). Execute three1->0 moves, then2->0,0->2,2->0, ending in3e0. Pair one old and one marked input in EACH first1->0. Use one of these root outputs together with the first2->0 output for the debt move0->2; merge the result with the remaining old singleton at2. Two untouched root outputs and the final returned output are three distinct final trees, EACH containing one removed marked input. Removing marks damages all three. The complete labelled forest, input partition and legal trace were independently checked, while complete reachability verifies the original c loses. This example is not Q-maximal and does not refute Q-selection or ASH*; it refutes the claimed universal two-component reconstruction bound.

Trying the SRC-0025 lexicographic no-merging proof exposes the next obligation precisely. Their fixed-target solution can omit unused input and invoke a no-cycle/unique tree path. Here all marked/unmarked sibling inputs must stay in the final forest; extracting only the first merged subtree can leave a losing residual frontier, and graph cycles may change every root choice. ## D. Path-cover credit constrains dominated minimal-counterexample candidates

Let G have a universal vertex a and n>=3. Let H=G-a. For c, let O={v in H:c(v) odd}. Empty vertices are not in O. Let theta(H[O]) be the minimum number of vertex-disjoint paths covering O, singleton paths allowed, theta(empty)=0. Put

    B(c,a) = c(a) + sum_(v in H) floor(c(v)/2) - theta(H[O]).

**Proposition41 (legal path-cover credit).** If B(c,a)>0, c stacks at a, reaching exactly B(c,a) pebbles by a legal consuming construction. Choose any path cover achieving theta. Even vertices export all pairs to a. For each odd path P, export pairs from every member, leaving one singleton each. With two available root pebbles, a->first(P), then successive moves along P, then last(P)->a consume that entire path, decreasing the root count by1. The net contribution of the path is sum_P floor(c(v)/2)-1.

Proof. The pair exports use only designated original inputs. An odd path task with pair credit E>=2 can begin with root0 and self-supply its two launching pebbles; its net gain E-1 is positive. A task with E1 requires root>=1 and has net0. A task with E0 requires root>=2 and has net-1. Process positive gains first, then zero tasks, then negative tasks. Since the total final pile B is positive, before each zero task the root pile is positive, and before any negative task it is at least B plus remaining negative tasks, hence>=2. Thus every launch/sweep/return is legal; all other designated inputs remain untouched until their task. Every odd vertex is consumed exactly once and all even vertices empty; the resulting root pile is exactly B. Paths need not be induced; only their edges and a's adjacency to both endpoints are used. QED.

This adapts the credited TreeStack positive-before-debt scheduling and October path operations. It is a sufficient rooted criterion, not a claimed necessary scalar message for arbitrary cyclic H.

Set k=n-1 and

    D(H)=max_(O subset V(H)) (|O|+2 theta(H[O])).

If c loses, B<=0, and the identity2B=|c|+c(a)-|O|-2theta gives |c|<=D(H). Consequently stack(G)<=D(H)+1. This maximum is a mathematical finite definition; no blanket subset computation was run. The upper alone does not establish AS extremality.

    clear(G) <= max(D(H)+3, 3r+7).

In the path-cover construction, some even export or odd path task using such an input yields an output at a whose final edge v->a is triangular: a-v has a common neighbor in H. Every nontrivial odd path has nonisolated endpoints; an isolated vertex can only be a singleton path.

If that task has positive gain (or is an even export), process it among the positive tasks and mark one of its outputs at a. Every subsequent positive odd-path task self-supplies at least TWO new root tokens before its launch, so the marked token can be avoided even when it is the only pre-existing root token. Even exports consume no root token. Preserve the marked output throughout. Immediately before that last move there are exactly2 tokens at a and2 at v, and no others. Choose common neighbor z in H; the legal v->z,a->z,z->a sequence clears instead. Thus c clears in every case. Terminal low layers and monotonicity above order make t an admissible threshold. QED.
