# Numbered-session execution and evidence protocol

## Entry (every separately invoked session)

1. Read LIVE GitHub remote main ref and exact commit/tree/parents; independently reconcile previous PR/merge and all intervening commits. Inventory all open/recent merged PRs, competing same-session branches, accessible protections/rulesets, actual workflow files/runs/jobs/check-runs/commit statuses. No hosted checks means **UNVERIFIED**, not green.
2. Read all authoritative files, exact primary problem spec, TreeStack boundary, source and claim catalogues, route log, gate/session/decision/failure ledgers, active campaign plan and previous INPUT/CLOSEOUT. Confirm session ID is unused.
3. Archive user invocation separately from the committed prospective prompt: quote raw text only if accessible in full, otherwise record `OWNER_INVOCATION_SUMMARY` and do not invent a verbatim hash.
4. Preregister S### plan, target hypotheses, mathematical stopping criteria, computational budget and required artefacts. A session may solve more than a single lemma but must remain one session and stop before executing next handoff.

## Research

- Mathematical proof: explicit theorem, full assumptions, complete proof and dependency DAG. A proposed route or source's assertion is not a new proof.
- Counterexample: adjacency and configuration in canonical form, exact total/threshold, dual independently developed reachability or impossibility verifiers, ability to reproduce outputs, and a complete logically sufficient certificate. A failed search is not a proof.
- Computations: preregister cutoff, exact exhaustiveness claims, symmetry proofs, code/environment versions, input and output hashes, machine resources and failure cases. Independent legal-move solver must be distinct from optimized method.
- Novelty: timestamped queries, primary citations, closest theorem, equivalence check and explicit uncertainty. Historical negative search cannot establish worldwide priority.
- Lean: pinned version and mathlib, kernel-trust boundary, no accepted sorry/admit/unreviewed axioms; require actual hosted CI records and independent checker at release.
- Do not promote SOURCE_STATED to PROGRAMME_PROVED or FORMALLY_CERTIFIED without corresponding independent evidence.

## Closeout

Reconcile and update ALL relevant structured/Markdown mirrors; include exact claims, sources, ruled-out approaches, artefact hashes, CI evidence, gate decision and honest limits. One atomic authored session commit on an isolated branch; PR with reviewable diff; non-force merge and independent main re-pin. If next session feasible, write a complete copy-ready FUTURE/UNEXECUTED next prompt into both NEXT_SESSION_PROMPT.md and S### closeout, without executing it. External publication, registration and contact are owner-authorised steps only.
