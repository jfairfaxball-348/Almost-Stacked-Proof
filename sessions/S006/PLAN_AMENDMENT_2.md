# Amendment 2 — exact buffer interfaces, before their computation

Generalize the rooted unary grammar to an arbitrary fixed off-source configuration c. States are (final vertex, consumed off-source vector d<=c, source-count residue, source count zero/positive). Store minimum positive source count for each residue and separate zero-source reachability. Binary productions split d exactly and add source counts; exclude the empty vector. Least-cost derivations, plus legal +3 at the occupied source, should characterize every possible initial source pile exactly. Prove non-bipartite finiteness by absorbing individual off-source pebbles with a labelled path pullback and then using rooted pure-pile minima. This is a necessary-and-sufficient interface with a fixed target, not a scalar balance rule or a universal ASH* proof.

Implement the finite labelled grammar for triangle with one leaf, source=attachment vertex0, all off-source vectors in {0,1,2}^3, all final targets. Compare every source count N=0..16-|c| against independent full legal-move rooted DP; source0 is a separate case, never filled by +3. Existing PLAN's tail bounds already cover these states. Retain exact minima/witness derivations and a second certificate checker for all local production inequalities and attaining derivations, so minima above the finite DP cap are not asserted from a cutoff. If memory/time exceeds 2GB/5min, record UNKNOWN and stop. This remains within PLAN's total budgets.

The pure-pile min-plus algorithm will emit attaining binary derivations and Bellman inequalities, checked by a separately written certificate verifier (not by reusing the optimizer). Check all finite values by legal postorder replay; independently compare the full forward and reverse rooted-winning masks for all registered small graphs through cap32, stopping at the 300,000-state/layer and existing time budget. Full-set equality is computed in memory; retain per-layer deterministic hashes and summary scopes, not a new threshold campaign. Universal exactness rests on the complete grammar proof, not on layer hashes.
